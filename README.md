# 🌐 AutoWifi Website

This repository contains the **official frontend website** for **AutoWifi** — a student-centric platform that explains the idea of automated campus Wi-Fi login and provides useful tech content for college students.

The website serves as:
- A **landing page** for AutoWifi
- A **post-login success page**
- A **student tech blog & tips hub**
- A **curated gadgets page**
- A **privacy policy page**

---

## ✨ Website Highlights

- 🎨 **Modern UI Design**
  - Glassmorphism cards
  - Animated gradient blobs
  - Smooth scroll-based animations
- 📱 **Fully Responsive**
  - Optimized for mobile, tablet, and desktop
- ⚡ **Fast & Lightweight**
  - Pure HTML, CSS, and JavaScript
  - No frameworks, no backend
- 🔒 **Privacy-Focused Messaging**
  - Clear privacy policy and transparent data usage
- 🎓 **Student-First Content**
  - Wi-Fi speed hacks
  - Daily tech tips
  - Gadget recommendations

